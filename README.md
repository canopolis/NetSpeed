# NetSpeed
Live download/upload speed in the Windows 10/11 tray (next to the clock).
Measures like realtimespeed.com: small 100 KB-1 MB test transfers to the nearest Cloudflare edge node every 3-5 s (about 100-300 MB per hour).

- Tray icon: top number (green) = download, bottom number (blue) = upload.
- Hover: full values. Click (left or right): menu with Start with Windows, floating box, units, adapter, Exit.
- Downloads: see Releases → NetSpeed_Setup.exe (installer) or NetSpeed_Portable.exe.
